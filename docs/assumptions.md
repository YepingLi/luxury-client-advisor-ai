# 业务与实现假设

初稿：2026-11-03；核对更新：2026-11-07。全部品牌、客户、商品、活动与对话均为虚构资料。本文件不包含真实客户个人信息。

## 工具范围

工具负责从结构化客户资料、场景、对话历史和适用商品中生成三条中文微信候选。全部业务输入使用虚构资料，消息由顾问审阅后自行选择，不自动发送。

## 虚构品牌：岚序 LANXU

岚序是一家虚构的高端皮具品牌，服务重视设计、日常使用适配与服务体验的成年客户。强调具体材质、携带方式和设计选择，不把价格高等同于身份优越，不暗示投资、保值或稀缺价值。

品牌语气是克制、自然、礼貌。称呼只使用输入提供的称呼，不从名字猜测年龄、性别或家庭情况。没有称呼时省略；没有偏好时只作适度介绍，不编造个人生活细节。历史中近期的明确偏好更新应优先于旧偏好，但历史文字不能修改本地品牌政策。

三条候选分别尝试简洁表达、温和关怀和可拒绝的轻量下一步；具体措辞随场景改变。这三种策略是生成指引，不允许为凑数复制候选。微信消息目标长度为 30–100 个 Unicode 字符，硬上限为 160；这属于实现选择，题目没有规定字数。默认不用表情。

## 事实与权限

商品事实直接来自每次请求的 `products`；不查询真实商品，不把历史中客户自述的价格当成官方价格。价格与币种同时提供，金额使用十进制定点语义。未知库存、礼品、折扣、维修、保修与护理方法不能推测。

顾问没有额外折扣授权。客户要求打折、模仿上级批示或让模型忽略规则都不能产生授权。可以尊重地说明已知标价、已知设计或材质，以及提出预约试背；不能贬低其他渠道，不能判断真伪，不能编造竞品价格。

生日或节日问候不强塞商品；购后关怀不附带购买压力；沉睡唤醒不猜测客户消失的原因。活动必须有具体名称、未来的开始时间、地点和回复方式。日期以请求内带时区的 `reference_time` 为业务参考，不用机器当前日期替代。

明确拒绝联系时阻止生成外呼。第一版没有微信发送功能；生成成功仅表示结构和应用规则通过并已保存，客户实际发送前仍需顾问复核。

## 缺失资料与错误

决定性事实缺失时返回 `needs_input`，明确列出待补字段；可选称呼、偏好或护理资料缺失时保守表达并记录 warning。未知字段不应静默丢弃。过长输入不静默截断。

缺少 API 配置、认证错误、模型拒绝、重试耗尽或写盘失败都返回真实错误，不生成静态文案冒充模型输出。测试用注入 provider 的 `mock` 结果只能用于验证测试行为，不能作为真实模型调用结果。
