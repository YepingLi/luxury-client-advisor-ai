# 固定虚构测试资料

数据版本：`fictional-inputs-1.0.0`。这些文件只包含输入与预先确定的检查点，不包含模型输出、人工评分或真实客户信息。

| 文件 | 数量 | 用途 |
| --- | ---: | --- |
| dev_12.jsonl | 12 | 每场景两例，独立请求与客户 ID，用于开发调试 |
| final_50.jsonl | 50 | 正式固定输入，场景数量 8／9／8／8／8／9 |
| final_50.metadata.json | 50 | 30 常规、10 可选信息缺失、10 难例及逐例预期检查点 |
| robustness.jsonl | 16 | 应被阻止或要求补资料的额外输入，不进入最终 50 例 |
| robustness.expected.json | 16 | 预期 status／error_code 及零模型调用要求 |
| dataset_manifest.json | — | 输入文件 SHA-256、逐例规范 JSON 哈希与固定集版本 |

所有业务参考时间明确带时区，固定在 2026 年 11 月。活动、节日、地点、客户和品牌均为虚构，不能当成实际公众活动。资料中的称呼由输入显式提供，模型不得从中继续推测年龄或家庭情况。

`build_fixtures.py` 可从项目根目录用 `python tests/data/build_fixtures.py` 重建这批静态输入；它不调用模型、不生成候选。最终集已验证及批量后如需修改输入，应升级数据版本并说明原因，不在最终评估中替换失败案例。首次冻结前修正了 FINAL-C08 的对话时间逆序，详情见缺陷记录。

本轮用户明确不调用模型 API；只做本地契约／失败路径验证及 pending 表格准备。输入就绪不代表真实生成通过，也不意味着最终 150 条候选已经存在。
